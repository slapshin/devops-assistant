# DevOps AI assistant — implementation plan

Planning documents follow the product/architecture/task structure used by the family-tree project.

- [Product plan](docs/PRODUCT_PLAN.md): confirmed requirements, workflows, first-release scope, and deferred work.
- [Architecture](docs/ARCHITECTURE.md): proposed stack, metric semantics, time windows, baselines, contracts, and runtime boundaries.
- [Technical decisions](docs/DECISIONS.md) and [UI specification](docs/UI_SPEC.md): T001 implementation defaults (versions, API/jobs, detector policy, budgets, screens).
- [Implementation tasks and agent handoff](docs/tasks/README.md): ordered T001–T010 backlog, dependencies, statuses, and the next-agent assignment.

The task index is the single source of implementation status. Each task contains its outcome, ownership, work, acceptance checklist, verification guidance, and completion record.

All implementation tasks T001–T010 are DONE (2026-09-30). The first release is validated against the packaged application and the live metrics source; evidence and remaining limitations are in [docs/RELEASE_CHECKLIST.md](docs/RELEASE_CHECKLIST.md).
